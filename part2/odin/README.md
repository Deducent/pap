# Help tools
- build
- run


## build
Give a number to it and it will try to find the listing.odin file in this **part2** directory and build it to the **builds** directory.
```sh
./build 67

# or

./build
```
If no number is specified it will just build all listing.odin files in the this **part2** directory.

## run
Needs one listing number specified.
Runs the the listing.odin file in the this **part2** directory and build it to the builds directory

```sh
./run 67
```
